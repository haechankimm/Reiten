## 1. 사이트 구조 한눈에 보기

Reiten은 사실 **사이트가 두 개**입니다. 도메인만 다를 뿐 같은 서버가 같이 돌립니다.

- **`reiten.kr`** — 손님이 보는 쇼핑몰. 상품을 보고, 담고, 결제하고, 리뷰를 남기는 곳.
- **`works.reiten.kr`** — 운영자만 로그인해서 들어가는 관리자 전용 사이트. 주문·재고·상품·매출을
  관리하는 곳. 손님은 이 주소로 들어와도 로그인 화면만 보이고, 로그인해도 관리자 계정이
  아니면 아무것도 못 봅니다.

두 사이트는 데이터를 완전히 공유합니다 — Works에서 상품 사진을 바꾸면 reiten.kr에도 바로
반영되고, reiten.kr에서 들어온 주문은 Works "전체 주문"에 바로 뜹니다. 별도로 동기화하거나
새로고침을 기다릴 필요가 없습니다(재고 관련 화면만 최대 15초 정도 지연될 수 있음 — 5번의
"재고가 다 떨어지면 자동으로 품절 표시되나요?" 참고).

## 2. 고객이 보는 사이트 (reiten.kr)

### 둘러보기 · 쇼핑
- **상품 목록/상세** — 색상·사이즈 선택, 실측 사이즈표, 상세 사진. 재고가 없는 색상·사이즈
  조합은 자동으로 품절 표시됩니다(Works에서 손으로 체크하지 않아도 재고 수량 기준으로
  실시간 반영).
- **상품 검색**(2026-09-04 추가) — 전체 상품 화면 위쪽 검색창에 이름을 입력하면 바로 필터링됩니다.
- **위시리스트**(2026-09-04 추가) — 상품 사진 위 하트 버튼으로 담아뒀다가 나중에 모아볼 수
  있습니다. 로그인 없이도 되지만, 담은 목록은 그 기기·브라우저에만 저장됩니다(다른
  기기에서는 안 보임).
- **품절 사이즈 재입고 알림 신청** — 원하는 사이즈가 품절이면 이메일을 남길 수 있고, 나중에
  그 사이즈가 다시 입고되면(Works에서 재고를 채우는 순간) 자동으로 안내 메일이 갑니다.
- **전체 품절 표시** — 모든 색상·사이즈가 0개인 상품은 사이트에서 사라지지 않고 상품 사진 위에
  "품절" 배지가 붙습니다(영어·일본어 화면에서는 Sold Out·売り切れ).
- **라이더 사이즈 추천**(2026-10-02 추가) — 상품 페이지에서 키·몸무게·보호대 착용 여부를 넣으면
  추천 사이즈를 알려주고, 버튼 하나로 그 사이즈를 바로 고를 수 있습니다. "어떤 사이즈를 사야
  하나요?" 문의와 사이즈 교환을 줄이기 위한 기능입니다.
- **룩북** — 코디 사진을 모아 보여주는 갤러리 페이지.
- **지퍼 참(charm) 커스터마이징 스튜디오** — 지퍼 슬라이더에 달 수 있는 참을 상품과 함께
  조합해볼 수 있는 별도 화면(해당되는 상품에만 노출).

### 장바구니 · 주문 · 결제
- **장바구니** — 담기, 수량 조절, 쿠폰 코드 입력(할인 자동 계산).
- **적립금**(2026-09-04 추가, 2026-10-02 적립 시점 변경) — 로그인한 회원의 주문이 **구매확정**되면
  포인트가 쌓이고(적립률은 Works "정보" 탭에서 조정, 기본 1%), 다음 주문의 장바구니에서 보유한
  포인트를 원하는 만큼 결제금액에서 차감해 쓸 수 있습니다. 결제하자마자 적립해 주면 "적립금으로
  다른 걸 사고 첫 주문은 반품"하는 악용이 가능해서, 물건을 받고 확정된 뒤에 주도록 바꿨습니다.
  주문이 취소되면 쓴 포인트는 돌려받고, 반품하면 반품한 만큼 쓴 포인트는 돌려받고 받은 포인트는
  회수됩니다. 사진을 첨부한 리뷰가 승인되면 추가 적립금도 받습니다(아래 "후기 · 문의" 참고).
- **구매확정**(2026-10-02 추가) — 배송이 끝난 뒤 7일이 지나면 자동으로 구매확정됩니다(배송 완료
  기록이 없으면 출고 14일 뒤). 고객이 주문조회·내 주문 화면에서 "구매확정" 버튼으로 먼저 확정할
  수도 있습니다. 반품·교환을 처리 중인 주문은 자동 확정되지 않습니다.
- **결제 수단 3가지** — 무통장입금(계좌이체 후 관리자가 입금 확인) / 신용카드 결제(포트원
  결제창, 결제 즉시 주문 확정) / **가상계좌**(2026-09-04 추가, 이 주문 전용 계좌가 발급되고
  그 계좌로 입금하면 무통장입금과 달리 관리자 확인 없이 자동으로 결제 완료 처리됨 —
  카드사(PG) 쪽 별도 심사가 끝나야 실제로 켤 수 있는 결제 수단이라 지금은 화면에 안 보일
  수 있음).
- **휴대폰 카드결제** — 휴대폰에서는 결제창이 새 화면으로 넘어갔다가 결제가 끝나면 주문완료 화면으로
  자동으로 돌아옵니다(2026-10-02 추가). 결제를 취소하거나 실패하면 그 이유를 보여주고 장바구니는 그대로 남습니다.
- **주문이 거절되면 정확히 알려줌**(2026-10-02 수정) — 쿠폰 소진·재고 부족·적립금 부족 등으로 주문이
  접수되지 않으면 그 이유를 보여주고, 접수되지 않은 주문에 대해 "주문이 접수되었습니다"나 입금 계좌를
  보여주지 않습니다(예전엔 실제로 없는 주문에 고객이 입금할 수 있었음).
- **참만 단독 주문 불가** — 참(무료)은 후디·집업 같은 상품과 함께 주문할 때만 살 수 있습니다. 참만 담으면
  장바구니에 안내가 뜨고 주문 버튼이 잠깁니다.
- **배송비 정책** — 일정 금액 이상 무료배송(쿠폰 할인 적용 *전* 금액 기준으로 판단).
- **비회원 주문 조회** — 회원가입 없이 주문번호 + 연락처만으로 자기 주문 상태를 확인 가능.
  금액은 상품 합계 → 쿠폰 할인 → 적립금 사용 → 배송비 → 총 결제금액 → 환불된 금액 순서로 한 줄씩
  보여줘서 합계가 맞게 보입니다(2026-10-02 수정). 입금 대기 주문이면 입금할 계좌도 다시 보여줍니다.
- **주문취소 신청**(2026-09-04, 사유 선택 방식 추가) — 아직 배송 전(입금대기·입금확인
  상태)인 주문은 고객이 비회원 주문조회 화면에서 직접 취소를 신청할 수 있습니다. 미리
  정해진 사유 중 고르거나 "기타"를 골라 직접 사유를 적을 수 있고, 이 사유들은 Works
  대시보드의 취소 사유 통계에도 반영됩니다.
- **반품·교환 신청** — 고객이 직접 신청하면 Works에 접수됩니다. 반품은 관리자가 받은 상품을 확인한 뒤
  환불해 주고(일부 상품만 반품 가능, 단순변심이면 반품 배송비를 빼고 환불), 교환은 환불 없이 새 상품을
  다시 보내 줍니다(보낸 운송장번호가 고객에게 메일로 감). 신청 화면에 이 안내가 함께 나옵니다.

### 계정 · 로그인
- **이메일 회원가입/로그인**, **카카오 로그인**(카카오 계정으로 바로 가입/로그인).
- **비밀번호 재설정** — 이메일 링크 방식.
- 로그인하면 "내 주문 내역"을 바로 볼 수 있음(비회원 조회보다 편리). 할인·적립금·환불 금액 줄과
  "구매확정" 버튼도 같은 방식으로 보입니다.

### 후기 · 문의
- **리뷰** — 실제로 그 상품을 구매한 사람만 남길 수 있도록 주문번호+연락처로 확인합니다
  (아무나 아무 상품에나 리뷰를 남길 수 없음). 사진 첨부, 인스타그램 아이디 노출, "도움돼요"
  공감 기능 포함. 등록 직후엔 바로 안 보이고 관리자 승인 후 노출됩니다. **사진을 첨부한 리뷰가
  승인되면 회원에게 적립금**이 지급됩니다(2026-10-02 추가, 기본 1,000원 — 금액은 Works "정보" 탭에서
  조정, 0으로 하면 꺼짐, 리뷰 하나당 한 번. 비회원 주문으로 쓴 리뷰는 적립할 계정이 없어 제외).
- **상품 문의(Q&A)** — 질문 남기기, 비밀글(작성자와 관리자만 열람) 지원. 문의를 작성하는
  동안 예전에 비슷한 질문에 이미 답변한 게 있으면 자동으로 먼저 보여줘서, 같은 질문을 또
  기다릴 필요 없이 바로 답을 찾을 수 있습니다. **비회원이 비밀글을 쓰면 답변 받을 이메일을 꼭
  남기도록** 안내하고(비회원은 비밀글 답변을 사이트에서 볼 방법이 없기 때문), 관리자가 답변하면
  그 이메일(회원이면 가입 이메일)로 답변이 바로 갑니다(2026-10-02 추가). 이 이메일과 관리자 내부
  메모는 공개 목록에 절대 나오지 않습니다(예전엔 내부 메모·담당자 표시가 누구에게나 보이던 문제 수정).

### 그 밖의 기능
- **다국어** — 한국어/영어/일본어 전환(헤더의 언어 메뉴). 오류 안내 문구(쿠폰 사용 불가, 재고
  부족 등)도 고른 언어로 나옵니다(2026-10-02 수정 — 예전엔 오류만 한국어로 나왔음).
- **검색 노출**(2026-10-02 개선) — 상품 화면 내용을 검색 로봇(네이버·구글)이 바로 읽을 수 있는 형태로
  함께 보내서 상품명·가격·사진이 검색 결과에 더 잘 잡힙니다. 네이버쇼핑에 올릴 상품 목록 파일도
  자동으로 만들어집니다(등록 방법은 5번 질문 참고).
- **실시간 고객센터 채팅** — 채널톡(ChannelIO) 위젯으로 방문자가 바로 문의 가능.
- **개인정보처리방침 · 이용약관** 등 법적 필수 페이지.
- 상품을 카카오톡·SNS에 공유하면 그 상품 사진·이름이 미리보기로 뜸(공유 시 항상 같은
  이미지만 뜨는 문제 해결됨).

## 3. 관리자 전용 사이트 Works (works.reiten.kr)

로그인하면 왼쪽에 메뉴(사이드바)가 있고, 화면 상단에는 알림 벨·라이트/다크 테마 전환·
한국어/독일어 언어 전환(동업자용)이 있습니다. 메뉴는 업무·결제·상품·마케팅·회원·운영·분석
카테고리로 묶여 있고, 카테고리 이름을 누르면 접었다 펼 수 있습니다(2026-09-03 개편). 각
메뉴에서 할 수 있는 일:

### 오늘
로그인하면 가장 먼저 보이는 화면. 오늘 매출·오늘 주문·입금 확인 대기·확인이 필요한 항목
총계를 한눈에 보여주고, 각 카드나 바로가기를 누르면 해당 메뉴로 바로 이동합니다. **인수인계
노트**(2026-09-15 추가)도 이 화면에 있음 — 관리자끼리 "오늘 특이사항"을 짧게 남겨두는
메모장으로, 교대 근무나 다음에 확인할 사람에게 전달할 내용을 적어두는 용도.

### 업무
- **전체 주문** — 모든 주문을 검색·필터링(상태·기간·검색어)해서 보고, 상태 변경(입금확인·
  배송중·완료·취소), 운송장번호 입력(입력하는 순간 고객에게 배송 시작 메일 자동 발송).
  **일괄 처리**로 여러 건을 한 번에 처리 가능(단, 취소는 사고 방지를 위해 일부러 건별로만
  가능). 각 주문마다 "이 주문에 무슨 일이 있었는지" 변경 이력도 확인 가능. 취소 처리하면
  재고 복원·카드결제(또는 가상계좌) 환불·고객 안내 메일까지 자동으로 한 번에 처리됩니다.
  **담당자 지정·내부 메모**(2026-09-15 추가) — 이 주문을 누가 처리 중인지 지정하고, 고객에게
  안 보이는 메모를 남길 수 있음. "내 담당만" 체크박스로 내가 맡은 주문만 걸러볼 수 있음.
  **부분 취소**(2026-10-02 추가) — 아직 출고 전(입금확인)인 주문에서 일부 상품만 취소하고 나머지는 그대로

### 직원·권한 (대표 전용)

직원이 늘어나면 **직원마다 Works에서 볼 수 있는 화면과 수정할 수 있는 범위**를 대표가 정할 수 있습니다.
왼쪽 메뉴의 "직원·권한"은 대표 계정에만 보입니다.

- **권한 3단계**: 접근 불가 / 보기만 / 보기+수정 — 주문, 반품, 재고, 문의, 결제, 상품, 쿠폰, 리뷰, 룩북,
  회원, 협업(캘린더·공지), 정보, 활동 로그, 대시보드 같은 영역마다 따로 고릅니다.
- 새 직원을 초대하면 기본으로 주문·반품·재고·문의·협업만 열려 있고, 나머지는 대표가 필요할 때 열어줍니다.
- **환불·주문취소(돈이 나가는 처리)**(2026-10-02 추가) — 입금된 주문 취소, 반품 환불, 부분 취소처럼 실제로 돈이
  나가는 동작만 따로 묶은 권한입니다. 직원에게는 기본으로 꺼져 있어서, 주문 권한이 있어도 이 권한이 없으면
  환불 버튼이 보이지 않습니다. 직원이 환불까지 처리해야 하면 대표가 "보기+수정"으로 켜 주세요.
- **PIN(2단계 확인)**: 로그인 비밀번호 다음에 숫자 6자리 PIN을 한 번 더 입력합니다. 처음 로그인하면 PIN을
  정하라는 창이 뜹니다. 직원이 PIN을 잊으면 대표가 "PIN 초기화"(직원이 새로 정함) 또는 "PIN 지정"을 할 수 있고,
  직원 비밀번호도 대표가 바꿔줄 수 있습니다. 본인 PIN은 오른쪽 위 "PIN 변경"에서 바꿉니다.
- **PIN 6회 오입력 잠금**(2026-10-02 추가) — PIN을 6번 틀리면 계정이 잠기고 "메인 관리자에게 잠금 해제를
  요청해 주세요"라는 안내가 뜹니다. 직원 계정은 대표가 "PIN 초기화"를 해 줘야 풀리고(직원 목록에 잠금 표시가
  뜸), 대표 계정은 30분 뒤 다시 시도할 수 있습니다. PIN 변경 화면에서 틀린 것도 같이 셉니다.

### 상품 사진 · 상세 콘텐츠 (컬러별)

상품 수정 화면의 "사진 · 상세 콘텐츠"에서 **컬러마다 따로** 사진을 올릴 수 있습니다. 위쪽 컬러 버튼(예: 블랙)을 누른 뒤
"+ 상품 사진 / + 상세 사진 / + 상세 영상 / + 상세 문구"를 누르면 그 컬러용으로 등록되고, 고객이 상품 페이지에서 블랙을
고르면 블랙 사진과 "공통" 항목만 보입니다. 원단·목 부분 같은 디테일 컷, 야간 반사 영상, 설명 문구는 상품 페이지 아래
"Details" 영역에 나옵니다. "모델 정보"에 "178cm · 70kg / L 착용"처럼 적으면 사이즈 선택 아래에 표시됩니다.
품절은 이제 "재고" 탭 수량으로만 정해집니다(0개면 자동 품절). 배송이 시작된 주문에는 5일 뒤 리뷰 요청 메일이 한 번 갑니다.

### 등급 표시 · 캘린더 기간 일정

대표 계정에서는 회원 목록·관리자 목록에 **★ 메인 관리자(금색) / 운영자(파랑) / 일반회원(회색)** 배지가 보이고, 직원(운영자)
화면에서는 "운영자 / 일반회원" 구분만 보입니다. 메뉴 맨 위에 내 이름과 등급이 표시됩니다. 캘린더는 시작일·종료일을 정하면
10/3~10/15처럼 기간 일정을 한 번에 등록할 수 있고, 달력에 막대로 이어서 보입니다.

### 회원 탈퇴 · 직원 "보기만" 권한

고객은 계정 페이지 맨 아래 "회원 탈퇴"에서 직접 탈퇴할 수 있습니다(진행 중인 주문이 있으면 불가, 적립금은 소멸,
주문 기록은 법정 기간 보관). 직원에게 어떤 화면을 "보기만"으로 주면 그 화면에서는 저장·삭제 버튼이 사라지고
"보기 전용" 안내가 뜹니다. 검색·내보내기는 그대로 쓸 수 있습니다.

### 긴급 오류 알림 (대표 전용)

결제·환불·메일 발송 실패처럼 바로 손봐야 하는 오류가 생기면 **텔레그램 메시지와 폰 푸시 알림**이 즉시 옵니다
(같은 종류는 30분에 한 번). "정보" 탭의 "긴급 오류 알림"에서 연결 상태를 보고 "테스트 알림 보내기"로 확인할 수 있습니다.
처음 연결할 때: 텔레그램에서 봇에게 /start 를 보내고(봇은 답장하지 않는 게 정상), **24시간 안에** "텔레그램 채팅 ID 찾기"를
누르면 나오는 숫자를 Render 환경변수 TELEGRAM_CHAT_ID에 넣으면 됩니다. 24시간이 지나면 텔레그램이 메시지를 지워서 안 찾아지니 /start 를 다시 보내세요.

## 4. 이 사이트를 움직이는 외부 서비스들

Reiten은 혼자 돌아가는 게 아니라 여러 외부 서비스와 함께 움직입니다. 각각 무슨 역할을
하는지, 문제가 생기면 어디를 봐야 하는지 정리했습니다.

| 서비스 | 역할 | 참고 |
|---|---|---|
| **GitHub** | 코드가 저장되는 곳. 코드를 고칠 때마다 여기에 기록이 쌓임(코드의 "구글 드라이브" 같은 개념). | 실제 배포는 여기서 바로 되는 게 아니라 아래 Render가 이 코드를 가져가서 실행함. 사이트가 쓰는 부품(라이브러리)에 보안 문제가 알려지면 매주 월요일 자동으로 "업데이트 제안(PR)"이 올라옴(2026-10-02 설정) — 자동 검사가 통과하면 합치기만 하면 됨 |
| **Render** | 실제로 서버를 24시간 켜두고 돌리는 호스팅 서비스. GitHub에 새 코드가 올라오면 자동으로 감지해서 새 버전으로 다시 배포함. | 무료 플랜은 아무도 안 들어오면 잠깐 잠들었다가 첫 방문자에게 30~50초 지연이 생길 수 있음 |

| **Resend** | 주문 접수·입금 확인·배송 시작·리뷰 승인 안내 등 고객에게 가는 자동 이메일을 실제로 발송해주는 서비스. | 고객이 답장하면 실제 CS 이메일로 옴 |
| **PortOne(포트원)** | 신용카드 결제를 실제로 처리해주는 결제 대행 서비스(PG). 카드사 심사도 이곳을 통해 진행됨. | 카드사 등록 심사가 끝나야 실제 카드결제가 열림 |

## 5. 자주 궁금해할 만한 것들

**Q. 상품 사진은 어떻게 올리나요?**
Works "상품" 탭에서 상품을 등록/수정할 때 사진 업로드 칸에 파일을 올리면 자동으로
Cloudinary에 저장되고 최적화됩니다. 별도 리사이징 작업은 필요 없습니다.

**Q. 재고가 다 떨어지면 자동으로 품절 표시되나요?**
네. Works "재고" 탭에서 실제 수량을 관리하고, 그 수량이 0이 되면 reiten.kr에서 자동으로
해당 색상·사이즈만 품절 표시됩니다(다른 색상·사이즈는 그대로 판매됨). 최대 15초 정도
지연될 수 있습니다(트래픽이 몰려도 서버 부담을 줄이기 위한 캐시 때문).

**Q. 쿠폰은 어떻게 만드나요?**
Works "쿠폰" 탭에서 직접 만들 수 있습니다. 정률(%) 또는 정액(원) 할인, 전체 상품 또는
특정 상품만, 최소 주문금액, 사용 기간·횟수 제한까지 자유롭게 설정 가능합니다.

**Q. 첫 구매·재구매 감사 쿠폰은 뭔가요?**
고객이 처음 결제를 완료하면 자동으로 감사 쿠폰이 이메일로 발급됩니다(할인율은 Works
"정보" 탭에서 조정 가능, 기본 1%). 같은 방식으로 누적 구매 횟수가 일정 기준(기본 5회)에
도달하면 재구매 감사 쿠폰도 자동 발급됩니다(기준 횟수·할인율 모두 "정보" 탭에서 조정
가능, 기본 5%). 둘 다 새로 설정하지 않으면 이 기본값 그대로 동작합니다. 이 항목들의
**"이름"은 자동 발급 로직이 정확히 그 이름으로 찾기 때문에 바꾸거나 지울 수 없게
보호돼 있습니다**(값만 자유롭게 수정 가능) — 실수로 이름을 바꿔서 자동 발급이 조용히
멈추는 걸 막기 위함입니다.

**Q. 적립금 적립률은 어떻게 바꾸나요?**
Works "정보" 탭에서 "적립금 적립률(%)" 항목의 값을 바꾸면 다음 결제부터 바로 반영됩니다
(감사 쿠폰 할인율과 같은 방식). 아직 이 항목을 만들지 않았다면 기본값 1%로 동작합니다.

**Q. 가상계좌 결제는 왜 안 보이나요?**
가상계좌는 카드결제와 별개로 PG사(카드사 심사기관) 쪽에 추가로 심사를 받아야 켜지는
결제수단입니다. 심사가 끝나기 전까지는 코드가 준비돼 있어도 고객 화면에 노출되지 않고,
심사 후 서버 설정 하나만 추가하면 별도 개발 없이 바로 켜집니다.

**Q. 관리자를 한 명 더 추가하고 싶어요.**
Works "정보" 탭에서 이메일만 입력하면 초대 메일이 발송됩니다. 상대방이 메일의 링크에서
직접 비밀번호를 설정하면 바로 관리자로 로그인할 수 있습니다.

**Q. 매출은 어디서 확인하나요?**
Works "대시보드" 탭에서 오늘/이번 달 매출, 최근 14일 추이, 베스트셀러, 기기별 매출까지
한 번에 볼 수 있습니다. 엑셀/CSV로 내려받아 별도로 정리할 수도 있습니다. 월별 정산(주문·쿠폰·환불
정리 엑셀)은 같은 화면 "월간 정산 리포트"에서 원하는 달을 골라 받으면 됩니다.

**Q. 반품 환불할 때 배송비는 어떻게 되나요?**
Works "반품·교환·주문취소 신청"에서 "환불 처리"를 누르면 사유에 따라 자동으로 계산됩니다. 고객 단순변심이면
반품 배송비를 빼고(처음에 배송비를 냈으면 3,500원, 무료배송으로 샀으면 돌아오는 배송비까지 왕복 7,000원),
불량·오배송처럼 우리 잘못이면 빼지 않고, 주문 상품을 전부 돌려받으면 처음 낸 배송비도 돌려줍니다. 계산된
금액은 직접 고칠 수도 있습니다. 2개 중 1개만 반품하는 것처럼 일부만 환불하는 것도 됩니다.

**Q. 적립금은 언제 들어가나요? 구매확정은 뭔가요?**
구매확정은 "고객이 물건을 잘 받았고 반품하지 않는다"가 확정되는 시점입니다. 배송이 끝나고 7일이 지나면
자동으로 확정되고(고객이 먼저 "구매확정"을 누를 수도 있음), 그때 적립금이 들어갑니다. 결제하자마자 적립하면
적립금만 쓰고 원래 주문은 반품하는 악용이 가능해서 이렇게 정했습니다.

**Q. 네이버쇼핑에 상품을 올리려면?**
네이버 쇼핑파트너센터에 사업자로 가입하고 입점 신청을 한 뒤, 상품 정보 등록 방식에서 "EP"를 고르고
상품 목록 파일 주소로 `https://reiten.kr/ep/naver.tsv`를 넣으면 됩니다. 이 파일은 사이트가 자동으로 최신
상품·가격으로 만들어 두고, 사진이 없거나 전부 품절인 상품은 알아서 뺍니다. 상품을 Works에서 고치면 다음
수집 때 네이버에도 반영됩니다.

**Q. 데이터 백업은 어떻게 되나요?**
매주 월요일 새벽에 주문·회원·상품·재고 등 전체 데이터가 관리자 메일로 자동 백업됩니다. 급할 때는 Works
"정보" 탭 "운영 점검 · 자동 백업"의 "전체 백업 받기"로 바로 내려받을 수 있습니다(대표 전용). 다만 "어제
오후 3시 상태로 되돌리기" 같은 정밀한 복구는 데이터베이스(Supabase) 유료 플랜의 기능이라, 매출이 늘면
유료 플랜을 권장합니다.

**Q. 사고(버그)가 생기면 어떻게 아나요?**
Sentry가 자동으로 에러를 감지하고, UptimeRobot이 사이트가 아예 안 열리는 상황을
감지합니다. Works 알림 벨에도 "시스템 오류" 항목으로 뜹니다. 결제·환불·메일 발송 실패처럼 급한 오류는
폰 푸시(와 텔레그램)로 바로 오고, 매일 아침 업무 요약에도 "운영 점검" 결과(메일 설정 문제, 발송 실패 등)가
함께 들어갑니다.
